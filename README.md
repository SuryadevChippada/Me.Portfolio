# Suryadev — Personal Portfolio

My personal portfolio and digital space for projects, experiments, writing, and things I enjoy building.

## Live

[suryadev-portfolio.vercel.app](https://suryadev-portfolio.vercel.app)

## About

This portfolio is a collection of my work across software, AI, computer vision, design experiments, and other projects I build while studying Computer Science at TU Darmstadt.

The site is intentionally more personal than a traditional portfolio and is designed to feel like my own space rather than a standard developer template.

## Built With

* React
* TypeScript
* Vite
* HTML
* CSS
* JavaScript

## Development

Clone the repository:

```bash
git clone https://github.com/SuryadevChippada/Me.Portfolio.git
cd Me.Portfolio
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```
